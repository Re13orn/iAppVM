# iAppVM 使用与调试

这是面向 iAppVM 使用者的独立操作指南，可用于支持 SKILL.md 的助手环境。跟随用户语言，优先给出当前问题所需的最短路径。无需开发仓库、Xcode、某台指定电脑或既有会话历史。

页面名称和功能可能随版本变化；先参考用户实际界面、导出的连接包 README/配置及客户端帮助。找不到功能时先确认版本，不把本指南当作用户已安装该功能的证明。

## 首先识别环境

- iAppVM 是基于 LiveContainer 的非越狱应用运行与测试容器；VM 是产品名称的一部分，不代表完整 iOS 系统虚拟化或越狱权限。
- 从用户当前任务识别目标导入实例和数据容器，避免仅凭 App 显示名选择；不要预设用户已有某个 IPA、工作目录或连接包。
- 只确认任务需要的信息：手机自动脚本不要求电脑工具；电脑连接才确认桌面系统、可用工具、Gadget 模式/版本、实际端口与配置。优先读取用户提供的界面或导出材料，缺少时给出取得方法。
- 内部出现 `iOSVM` 名称可能是历史兼容标识；不要为了品牌一致改写路径、配置键或 URL scheme。
- 不预设设备已配对、解锁、启用开发者模式或配置签名；这些仅在相应导入、启动或连接步骤失败且证据相关时核查，不当作所有任务的前置清单。
- 按当前任务操作所选 App；指南本身不授权重装、删除数据、改签名身份、切换系统代理或读取其他 App 的数据。

## 必须保留的运行边界

| 普通越狱工作流中的习惯 | iAppVM 中的做法 |
|---|---|
| 全局 frida-server，`frida -U -f bundle.id` | 每个目标进程内加载 Gadget，使用其实际端口与认证配置连接；电脑 USB 转发后用 `-H` |
| 可以枚举全机进程 | Gadget 的监听接口通常只暴露自身 `Gadget` / `re.frida.Gadget` |
| JS 加载成功就能任意 Interceptor | 默认 `code_signing=required`；区分 JS 执行、桥接可用与代码修改权限；既有 gum-graft 路线仅支持提前插桩的目标 |
| 脚本中的 ObjC/Swift 必然是全局变量 | Frida 17 的语言桥接需要为 Gadget/Python create_script 场景打包；不能根据 CLI 能运行推断手机原始 JS 也能运行 |
| 手机脚本和电脑随时同时连接 | 本版本自动脚本用 `script-directory`，电脑连接用 `listen`，需要切换并重启目标 |
| 直接读取任意系统 App 的沙盒 | 浏览选中导入实例的数据容器，不能据此访问任意原生安装 App 或系统文件 |

不要通过把 `code_signing` 改成 `optional`、重置目录权限、启动全局 frida-server 等猜测来解决问题。JIT 是否可用、何时启用、Gadget 加载前是否具备调试状态都需证据；“使用 JIT 启动”不是通用修复按钮。

## 根据任务读取对应说明

- 导入 App、启动自检、配置预设、脚本库、本地自动运行、版本与签名、沙盒及运行状态：读 [references/app-workflows.md](references/app-workflows.md)。
- 标准 `frida` CLI、USB 转发、配套客户端、早期加载、Frida 17 适配及连接排错：读 [references/frida.md](references/frida.md)。
- 单 App HTTP/SOCKS5、流量可见性、代理握手与加载回执：读 [references/network.md](references/network.md)。
- 使用 [assets/diagnose.js](assets/diagnose.js) 验证 JS 生命周期、PID、架构与代码签名策略。它不 Hook、不联网、不读取用户数据；使用前复制到任务目录或导入手机脚本库。
- 普通 CLI 需要认证时，用 [scripts/make-cli-options.py](scripts/make-cli-options.py) 从所选 App 导出的配置生成私有 `-O` 参数文件（Unix 权限 0600；Windows 使用用户私有目录并确认 ACL），避免把 token 写在命令行中。

## 排查与交付

先定位链路断点：配置保存 → 插件签名/加载 → 本次目标启动 → JS 执行 → Hook 能力 → 电脑连接/日志。每次只验证相关一层；无副作用的诊断通过后才适配用户的目标脚本。

Gadget 文件存在、签名记录、窗口/PID、Gadget 实际加载回执、脚本输出、电脑心跳分别给出证据。普通 CLI 没有手机回执，不以 UI“未确认”否定一个已经成功的连接。

报错时保留必要的错误、版本、模式和进程信息；认证 token、连接包和用户沙盒文件不公开输出。不要为确认运行状态批量导出钱包或其他 App 的私人数据。

只报告已验证的结果。下载成功不代表已应用；代理握手通过不代表业务流量全部经过代理；脚本 console 有输出不代表 Hook 已命中。

## 可移植性与证据

所有附带资源都从本 Skill 文件夹按相对路径定位；命令中的工作目录、配置文件、设备 UDID、端口、Gadget 版本和脚本路径必须取自当前任务。示例端口只是可替换的本地端口，不代表手机固定端口。

连接包可从 App 导出；不要要求普通用户先克隆开发工程。某版本没有连接包或配套客户端时，使用它实际支持的标准 CLI 路径，不凭空承诺手机回执。电脑没有 Python/Frida/USB 转发工具时，按所用系统提供安装方法，或采用无需电脑的自动脚本路径；不强制切换用户的工具。

可以报告本次版本、模式、配置状态和实际验证结果；不沿用其他用户、其他设备、历史测试的成功或失败结论。版本信息或实现细节不足时明确适用条件，避免猜测。
